## Proposed minimum workflow

1. **Mechanical pass over every item.** Use existing validators, exact citation identity and caption boundary helpers. Report missing/mismatched IDs, duplicate records, metadata contradictions and raw-duration conflicts without model calls. Deterministic/no-change results do not imply semantic correctness. Distinguish safely repairable envelopes from unresolved timing conflicts. Preserve separate visual windows.
2. **Inspect and draft per article.** Send selected captions once per bounded bundle, with nearby context separately labeled. Return all requested unit keys and proposed supported/needs-fix/uncertain/needs-footage outcomes. For each changed unit, include replacement text or an explicit quarantine proposal, selected support IDs and a concise finding. Labels/categories can have editorial dispositions; technical conditions and ratings need support. Full registry repetition is unnecessary: use exact collision indexes and bounded relevant alternatives, while the global collision check still covers all articles.
3. **Reduce large articles with claim coverage.** A field supported across several chunks must have complete, traceable coverage of every clause. No missing row/unit, unchecked chunk or any-supported shortcut can clear it. Necessary verification input that cannot fit stays split/pending; never let a reducer treat arbitrary model summaries as transcript evidence.
4. **Verify separately against the proposed result.** A fresh isolated call receives the exact selected source and complete proposed unit, without relying on the draft's verdict or confidence. Check object/role/conditions, each excerpt/reason clause, relation identity, ratings and field synthesis. Python rejects foreign IDs, missing/duplicate unit keys, stale fingerprints and unauthorized changes. Two calls to the same configured model are separate checks, not independent proof of truth. Evaluate correlated failures explicitly.
5. **Produce a reviewable private repair plan.** Show old/new values, findings, verifier disposition and source IDs. Whitelist changes to editorial prose/facets/aliases and explicit quarantine dispositions. Preserve IDs/slugs, source timestamps/IDs, visual status, provenance and unrelated records in the first implementation. No arbitrary model file paths or commands. Archive originals; apply only reviewed plans under the KB lock with stale-input checks, atomic replacement and recoverable checkpoints. Never bulk-promote the generated review queue or copy proposed-supported statuses into editorial approval.
6. **Close the changed review and publication stages.** Recompute fingerprints, recheck the actual repaired content, and record full article coverage. Publish only reviewed canonical YAML. Run ordinary batch checks after applied repairs and the strict full-audit gate before campaign completion/resumption. Report retained, repaired, quarantined, unresolved, stale and footage-needed outcomes separately; reducing public inventory is not the same as correcting every original article.

The reviewer can assess concrete batches and exceptions instead of writing one-off repair scripts and retyping every ordinary unit. Footage, contradictory/ambiguous captions, uncertain identity and unresolved timing stay in the exception queue. No automation can honestly mark unwatched demonstrations verified.
